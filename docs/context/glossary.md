# Glossario

- API: backend consumido pelo aplicativo.
- DAO: objeto de acesso a dados Room.
- DTO: objeto que representa payload de rede.
- Entity: objeto persistido no banco local Room.
- Domain: objeto usado pela regra da aplicacao.
- Mapper: conversor entre DTO, Entity e Domain.
- Repository: classe que coordena fontes de dados.
- Room: biblioteca Android para persistencia SQLite.
- Scan: captura e envio de imagem do medicamento para reconhecimento.
- OCR: reconhecimento optico de caracteres.
- Offline first: diretriz de persistir localmente e sincronizar quando possivel.
- Single Source of Truth: uma fonte principal para leitura do estado, preferencialmente Room para dados locais.
- WorkManager: mecanismo Android para jobs adiaveis e resilientes.
- AlarmManager: mecanismo Android para alarmes/notificacoes em horarios especificos.
- Hilt: injecao de dependencias usada no app.
- ViewModel: classe responsavel por estado e eventos de tela.
- Compose: toolkit declarativo de UI Android.
