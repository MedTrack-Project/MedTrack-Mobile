# Stack

## Linguagem e plataforma

- Kotlin
- Android
- Gradle Kotlin DSL

## UI

- Jetpack Compose
- Material 3
- Navigation Compose

## Assincrono e estado

- Coroutines
- ViewModel
- StateFlow e SharedFlow
- collectAsStateWithLifecycle

## Dados

- Room
- SQLite
- SharedPreferences privado com JWT cifrado por chave não exportável do Android Keystore e excluído
  de backup
- Gson

## Rede

- Retrofit
- OkHttp
- HttpLoggingInterceptor em nivel BASIC somente no debug

## Injecao de dependencias

- Hilt
- KSP

## Câmera e processamento

- CameraX para preview e captura
- Retrofit/WorkManager para scan remoto online e enfileirado

## Jobs e notificacoes

- WorkManager
- AlarmManager
- BroadcastReceiver
- Android notifications
